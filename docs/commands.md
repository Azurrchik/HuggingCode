# Команды HuggingCode

HuggingCode использует slash-команды для навигации, настройки модели, работы с проектом и управления сессиями. При старте сразу открывается главное меню; `Esc` переводит к диалогу, `Ctrl+P` возвращает меню, `Ctrl+J` переключает Chat и Trajectory, а `Ctrl+M` или резервный `Ctrl+O` открывает выбор модели. В интерактивном поле введите `/` и нажмите `Tab`, чтобы увидеть подходящие команды.

> Самый быстрый способ получить точную подсказку — `/help <команда>`. Например, `/help model` объясняет выбор модели, а `/help theme` — изменение цветов.

## Модель и интерфейс

| Команда | Краткое описание |
|---|---|
| `/model` | Открыть интерактивный live-каталог текущего провайдера; поиск, фильтры и policy выбираются клавиатурой. |
| `/model <ID> [policy]` | Установить точную модель с policy `fastest`, `cheapest` или `preferred`. |
| `/models [поиск]` | Загрузить и вывести модели текущего провайдера; для custom API показываются все модели из `<Base URL>/models`. |
| `/effort [уровень]` | Посмотреть или изменить `reasoning_effort` для поддерживающей его модели. |
| `/theme`, `/color` | Открыть picker цветовых тем. Тема применяется сразу и сохраняется. |
| `/theme <имя>` | Применить `ember`, `ocean`, `forest`, `violet`, `midnight`, `rose` или `mono`. |
| `/mode [режим]` | Посмотреть или выбрать `manual`, `accept-edits`, `plan`, `safe-auto` или `full`. |
| `/status` | Показать модель, режим и workspace. |
| `/trajectory [поиск]` | Открыть журнал наблюдаемых этапов, tool calls и результатов; аргумент фильтрует события. |
| `/chat` | Вернуться из Trajectory к обычному разговору. |
| `/doctor`, `/checkup` | Вывести платформу, shell, хранилище токена, usage и диагностику сессии. |

## Контекст и сессии

| Команда | Краткое описание |
|---|---|
| `/context` | Показать оценку размера истории и порог сжатия. |
| `/compact [фокус]` | Сжать историю до рабочего резюме. |
| `/clear`, `/new`, `/reset` | Очистить контекст и сохранить сессию. |
| `/sessions [поиск]` | Найти локально сохранённые сессии. |
| `/resume <ID>` | Восстановить сохранённую сессию. |
| `/branch [имя]` | Создать альтернативную ветку текущей сессии. |
| `/rename <имя>` | Переименовать текущую сессию. |
| `/export [файл.md]` | Экспортировать разговор в Markdown внутри workspace. |

## Проект, проверки и review

| Команда | Краткое описание |
|---|---|
| `/verify`, `/run` | Найти и запустить lint, test или build с применением текущих разрешений. |
| `/undo` | Восстановить последний поддержанный checkpoint с правками агента. |
| `/diff` | Показать текущий Git diff без изменения файлов. |
| `/review [фокус]`, `/code-review` | Провести read-only обзор diff: ошибки, регрессии, edge cases и тесты. |
| `/security-review [фокус]` | Провести read-only анализ diff на секреты, инъекции, path traversal и другие риски. |
| `/simplify [фокус]` | Найти дублирование и избыточную сложность без применения правок. |
| `/plan [задача]` | Переключиться в `plan` mode и при необходимости построить план реализации без записи файлов. |
| `/init` | Создать шаблон `HUGGINGCODE.md` — локальной памяти и соглашений проекта. |
| `/memory` | Показать загруженную память проекта. |
| `/memory add <текст>` | Дополнить `HUGGINGCODE.md` после необходимых подтверждений. |

## Навыки, вложения и подзадачи

| Команда | Краткое описание |
|---|---|
| `/skills`, `/reload-skills` | Показать Markdown-навыки из `.huggingcode/skills`. |
| `/skill <имя> [аргументы]` | Запустить выбранный Markdown-навык. |
| `/<имя-навыка> [аргументы]` | Короткая форма запуска существующего project skill. |
| `/attach <путь>` | Добавить UTF-8 текстовый файл из доверенного workspace к следующему запросу. |
| `/attach clear` | Очистить очередь файловых вложений. |
| `/subtask <задача>` | Запустить локальную исследовательскую подзадачу. |
| `/tasks`, `/agents` | Показать состояние локальных подзадач. |
| `/stop <ID>` | Остановить регистрацию результата выбранной подзадачи. |

## Учётная запись и выход

| Команда | Краткое описание |
|---|---|
| `/logout` | Удалить защищённо сохранённый API key текущего провайдера, не затрагивая ключи остальных провайдеров. |
| `/exit`, `/quit` | Завершить HuggingCode. |
| `/help [команда]` | Показать весь каталог команд или точную справку об одной команде. |

## Границы безопасности

Режим `full` требует фразу `ENABLE FULL MODE` и действует только до закрытия приложения. Он не отменяет границы workspace, проверку символьных ссылок, защиту секретных файлов или блокировку shell-команд с внешними путями, сетевыми transfer-утилитами и вложенными интерпретаторами.
