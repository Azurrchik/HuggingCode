# HuggingCode 0.4 — Architecture

## Runtime boundaries

`platform.js` является единственной точкой, которая знает об ОС. Он сообщает shell adapter, protected credential backend и сведения для `/doctor`. Остальные модули используют только компактные интерфейсы `CredentialBackend` и `ShellAdapter`.

```text
TUI → Controller → Agent → Hugging Face Inference Providers
      │             │
      │             └── Workspace → ShellAdapter
      │
      ├── ModelCatalog → router.huggingface.co/v1/models
      ├── Session / checkpoint / permission policy
      └── CredentialBackend → DPAPI | Keychain | Secret Service | session-only
```

## ModelCatalog

`model-catalog.js` нормализует ответ `GET /v1/models`, отсеивает модели без chat capability и создаёт ранжированный список. Список в памяти обновляется вручную через picker. Отдельный static fallback обеспечивает доступ к популярным coding-models при временной недоступности API.

Каждая запись содержит `id`, `label`, `contextLength`, `maxOutputTokens`, `provider`, `inputPrice`, `outputPrice`, `supportsTools`, `supportsVision` и локальные policy options: `fastest`, `cheapest`, `preferred`. `formatModelSelection` не добавляет повторный policy suffix и позволяет любой ручной идентификатор.

## TUI layout

`App.js` владеет состоянием turn, overlay и palette. Layout состоит из `HeaderBar`, `TranscriptView`, `Overlay`, `FooterBar` и `Composer`.

| Layer | Responsibility |
|---|---|
| HeaderBar | Product name, workspace basename, model, context %, permission mode, turn state. |
| TranscriptView | User blocks, assistant streaming, collapsed reasoning, tool/diff cards, verification outcomes. |
| Overlay | Model picker, command palette, pending approval. Всегда получает фокус выше composer. |
| FooterBar | Queue count, shortcut hints и session indicator. |
| Composer | Multi-line text, input history, slash completion, command palette trigger. |

## Event model

Controller продолжает выдавать доменные события. `transcript.js` нормализует их в UI-rows. Дополнительные presentation-only rows не записываются в agent history. Overlay interactions вызывают controller methods, не симулируют user prompt.

## Security

1. Secret file policy и workspace containment остаются server-side на уровне Workspace.
2. Approval всегда проходит через `decidePermission` до рендера карточки.
3. Picker никогда не показывает токен и не сохраняет provider credentials.
4. session-only fallback не записывает token на диск и явно показывает это в status/doctor.
5. `ShellAdapter` получает command только после permission policy; он не меняет allowlist режима `safe-auto`.
