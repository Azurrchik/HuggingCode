# Технологическая основа DeepSeek Harness и выбор HuggingCode Desktop

Официальный DeepSeek Harness — это Node.js agent harness на плагинном ядре Cordis. Его документированный способ запуска `npx @deepseek-ai/dsh web` поднимает локальный Web UI на `127.0.0.1:3080`; официальная страница описывает именно Web UI и traceable append-only session log, а не собственный выпущенный native desktop runtime.[1] [2]

Показанный интерфейс соответствует Web UI с Chat и Trajectory. В официальном описании Trajectory фиксируются события выполнения: системный контекст, обращения к модели, tool calls, результаты и другие injections. HuggingCode намеренно показывает безопасный поднабор наблюдаемых событий: задача пользователя, этап, tool call, команда, правка и результат. Скрытые рассуждения и системные инструкции не выводятся в интерфейс.[2]

Для cross-platform desktop wrapper известная реализация `hairyf/deepseek-harness-desktop` использует **Tauri 2**: WebView/React renderer и Rust backend, который управляет локальным DSH-процессом и отображает локальный Web UI. Она выпускает Windows, macOS и Linux пакеты.[3]

## Решение для HuggingCode 0.5.0

HuggingCode Desktop следует перевести с первоначальной Electron-prototype оболочки на **Tauri 2** как на тот же desktop engine, который использует публичная cross-platform desktop wrapper DeepSeek Harness. Внутренний agent controller HuggingCode, системное защищённое хранение токена, ограничения workspace и безопасный Trajectory сохраняются. Пользовательский интерфейс будет независимой реализацией и не будет копировать код или бренд DeepSeek Harness.
